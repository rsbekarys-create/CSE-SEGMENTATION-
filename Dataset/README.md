# Kazakh Educational QA Dataset

This directory contains the Kazakh educational question-answer dataset
used in the study:

"The Impact of Preliminary CSE Segmentation on Training Neural Models
for Kazakh QA"

## Dataset Contents

The dataset contains Kazakh question-answer pairs related to programming
education.

Experimental dataset sizes:

- Clean representation: 14,991 QA pairs
  - Training: 13,491
  - Test: 1,500

- Segmented representation: 14,998 QA pairs
  - Training: 13,498
  - Test: 1,500

- Strict-fair paired intersection: 6,759 QA pairs
  - Training: 6,083
  - Test: 676

The train/test partitions were generated using a 90/10 split with
shuffling and random seed 42.
