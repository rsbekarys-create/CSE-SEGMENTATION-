## Dataset

The Kazakh educational question-answer dataset used in the experiments
is available in the `dataset/` directory.

Dataset sizes:
- Clean representation: 14,991 QA pairs
- Segmented representation: 14,998 QA pairs
- Strict-fair paired intersection: 6,759 QA pairs
- Strict-fair training set: 6,083 paired items
- Strict-fair test set: 676 paired items
